🤖 AI Tic-Tac-Toe
A full-stack AI-powered Tic-Tac-Toe web application where users play against an intelligent computer opponent using the Minimax Algorithm. The project combines a responsive frontend, a Spring Boot REST API, and a MySQL database to deliver an engaging gameplay experience while storing game results.
________________________________________
✨ Features
•	🎮 Play against an AI powered by the Minimax Algorithm 
•	🧠 AI always chooses the best possible move 
•	💾 Store completed game results in MySQL 
•	📊 View previously played matches 
•	🔄 Real-time game status updates 
•	📱 Responsive interface for desktop and mobile 
•	🔗 REST API communication between frontend and backend 
•	🚀 Clean layered architecture using Spring Boot
