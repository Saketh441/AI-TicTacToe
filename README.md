# 🤖 AI Tic-Tac-Toe

A full-stack AI-powered Tic-Tac-Toe web application where users play against an intelligent computer using the Minimax Algorithm.

---

## ✨ Features

- ✅ Play against an AI opponent
- 🎯 AI uses the Minimax Algorithm
- 💾 Save game results in MySQL
- 📜 View previous game history
- ⚡ Fast and responsive interface
- 🔗 Spring Boot REST API integration

## ▶️ How to Run

1. Clone the repository.
2. Open the backend in IntelliJ IDEA.
3. Configure MySQL.
4. Run the Spring Boot application.
5. Open `index.html` in your browser.
